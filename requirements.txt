# Pinned with upper bounds on purpose.
#
# This file previously said `mcp>=1.0.0`. When mcp 2.x shipped it removed the
# decorator API the server was built on, so a fresh install produced a server
# that raised AttributeError at import and a container that could not start.
# An unbounded range on the library you are built against is a time bomb.
#
# fastmcp brings mcp, starlette and uvicorn with it, so they are not listed
# separately. httpx is listed because this code imports it directly.

fastmcp>=4.1.4,<5
httpx>=0.28.1,<0.29
